# meu-segundo-cerebro
Meu segundo cérebro: estudos, aprendizagem e documentação da minha jornada inicial em programação.
Este repositório documenta meu segundo cérebro, criado como parte de meu processo de aprendizagem e organização dos estudos.

*Objetivo
 Organizar conhecimentos, matérias e fontes de estudos em um único lugar, facilitando a consulta, a revisão e a continuidade do             aprendizado.
 O foco inicial é minha jornada de aprendizagem em programação desenvolvimento de sistemas.

*Organização de estudos
 O conteúdo está organizado a partir dos principais assuntos estudados ,como:
 * Algoritmos e lógica de programação
 * Fundamentos de programação
 * Python
 * Analise e Desenvolvimetnos de Sistemas
 * Outros conteúdos relacionados á tecnologia

*Fontes de conhecimento
  O segundo cérebro reúne diferentes fontes utilizadas durante os estudos , incluindo:
  * Livros
  * Cursos
  * Conteúdos encontrados no youtube

*Como estou utilizando
    A ideia é utilizar este repositório para:
  * Registrar o que estou aprendendo;
  * Organizar minhas fontes de conhecimento;
  * Facilitar revisões futuras;
  * Relacionar diferentes assuntos;
  * Aconmpanhar minha evolução na programação.

*Jornada de aprendizagem
Este projeto será atualizado conforme novos conhecimentos forem adquiridos. A intenção é transformar o repositório em uma base de conhecimento pessoal que possa crescer junto com minha formação em Análise e Desenvolvimento de Sistemas.
